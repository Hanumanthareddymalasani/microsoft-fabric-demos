# Microsoft Fabric Lakehouse Basics

## Objective

Demonstrate the creation and usage of a Microsoft Fabric Lakehouse for data engineering workloads.

## Components Used

* Microsoft Fabric Workspace
* Lakehouse
* OneLake
* Notebook
* Data Pipeline

## Steps

### 1. Create a Lakehouse

* Open Microsoft Fabric
* Navigate to the workspace
* Create a new Lakehouse

### 2. Load Data

* Upload CSV files into the Files section
* Create tables from uploaded data

### 3. Explore Data

* Query data using SQL Endpoint
* Validate records

### 4. Notebook Development

* Create a notebook
* Read data from Lakehouse tables
* Perform transformations using PySpark

### 5. Save Results

* Write transformed data back to the Lakehouse

## Architecture

Refer to the screenshots folder for architecture diagrams and implementation screenshots.

## Learning Outcomes

* Understanding OneLake storage
* Creating and managing Lakehouses
* Using Notebooks with PySpark
* Querying data using SQL Endpoint
* Building a basic Fabric Data Engineering solution
